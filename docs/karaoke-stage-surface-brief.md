OWN-WORLD: Use the existing app/globals.css tokens for backgrounds, surfaces, text, accent and semantic states. Retain the real-track meter and subdued measured rings.

STORY: Join friends, register a song as its turn owner, choose an optional duet partner, prepare each microphone, then start singing. Explicit local/received labels prevent mistaking local activity for successful delivery.

FIRST VIEWPORT: Desktop uses one viewport: video and compact mic strips beside an independently scrolling queue. Playback controls remain visible; song entry, friends and audio settings expand on demand. Mobile stacks the desk above the queue. Fullscreen is available.

FORM: An extension of the existing CineMind interface. Karaoke room routes use the immersive app shell without the site header/footer or floating actions; library tabs remain inside the page. The 40-band real-track canvas is a compact signal strip with separate local/received labels.

VALIDATION: Chromium checks at 1440×900, 1366×768 and 390×844 passed; desktop/laptop transport controls fit the viewport. Synthetic audio only. Real multi-network duet acceptance remains pending. No new raster assets.
